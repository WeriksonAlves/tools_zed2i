# tools_zed2i

Modular ROS2-based toolkit for ZED2i camera integration.

## Installation (development mode)

```bash
python -m venv .venv
source .venv/bin/activate
pip install -e .
```

## Structure

- `src/tools_zed2i/` → Main package
- `scripts/` → CLI tools
- `examples/` → Usage examples
- `configs/` → YAML configuration files
